-------------bearer token method----------------
1. What is Bearer Token?
👉 A secret key given after login
👉 Used to access protected APIs
Bearer Token = Key to access protected API

workflow:
Login → Get Token → Use Token → Access API

2. Setup Steps
✔ Install Sanctum
composer require laravel/sanctum    ---in cmd
✔ Publish Migration
php artisan vendor:publish --provider="Laravel\Sanctum\SanctumServiceProvider"    ---in cmd
✔ Run Migration
php artisan migrate    ---in cmd

👉 Creates:

personal_access_tokens table
✔ Add in User Model(user.php inside models folder)
code:
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens;    //its important for generate token and add generate token line with login Controller
}
🔐 3. Login → Generate Token (LoginController.php)
use Illuminate\Support\Facades\Auth;

public function login(Request $request)
{
    if (!Auth::attempt($request->only('email', 'password'))) {
        return response()->json(['message' => 'Invalid credentials']);
    }

    $user = Auth::user();

    $token = $user->createToken('api-token')->plainTextToken;  // this is important line for generate token after login

    return response()->json([
        'token' => $token
    ]);
}
